# Dey6 — сайт русификаторов

Готовый статический SEO-сайт. В каталоге 11 переводов с текущего Boosty, отдельная страница для каждого проекта и актуальные ссылки на русификаторы.

## Перед публикацией — 1 обязательный шаг

1. Открой `SET_DOMAIN.bat`.
2. Вставь реальный адрес будущего сайта, например `https://dey6.ru` или адрес Cloudflare Pages.
3. Скрипт заменит плейсхолдер во всех canonical URL, Open Graph, sitemap.xml и RSS.

Без этого сайт откроется, но SEO-метаданные будут указывать на технический плейсхолдер.

## Что уже сделано для SEO

- отдельный статический URL для каждого русификатора;
- уникальные `<title>` и meta description;
- canonical + hreflang;
- Open Graph + Twitter Card;
- JSON-LD: WebSite, CollectionPage, Person, Article, VideoGame, BreadcrumbList, DownloadAction;
- `sitemap.xml`, `robots.txt`, `rss.xml`;
- поисковая страница с `?q=`;
- семантические заголовки, хлебные крошки и внутренние ссылки;
- `manifest.webmanifest`, favicon, 404;
- security headers (`_headers`) для Cloudflare Pages / Netlify;
- RSS и `llms.txt`.

## Публикация на Cloudflare Pages

Загрузи всю папку как статический сайт. Build command не нужен, output directory — корень проекта. После выдачи адреса Pages запусти `SET_DOMAIN.bat` с этим адресом и залей обновлённые файлы ещё раз.

## Публикация на GitHub Pages

Создай репозиторий, загрузи содержимое этой папки в ветку `main`, затем включи Pages через GitHub Actions. Workflow уже лежит в `.github/workflows/pages.yml`. Если сайт будет жить в подпапке вида `username.github.io/repo/`, лучше использовать собственный домен или Cloudflare Pages: текущие внутренние URL рассчитаны на корень домена.

## После публикации

Добавь домен в Google Search Console, отправь `https://ТВОЙ-ДОМЕН/sitemap.xml`, затем запроси индексацию главной и 3–5 самых важных страниц. Не нужно спамить ключевыми словами: уникальные заголовки и тексты уже сделаны.

## Источники контента

Посты перенесены с `https://boosty.to/dey_6`. Сохранены ссылки на оригинальные посты и на архивы русификаторов. Для `Hello, Goodbye` не дублируется ссылка на готовую копию самой игры; на сайте оставлена только ссылка на патч/русификатор и оригинальный пост Boosty.
